# Resources

`WarcraftApi.json` contains a compact derived index for JASS IntelliSense:
symbol names, type names, parameter names/types, return types, and global
symbol metadata. It does not contain the source text or function bodies from
Blizzard's `common.j` or `Blizzard.j` files. Initial data was generated from
locally installed Warcraft III script declarations; those original files are
not included in this repository or VSIX.

The JASS / vJASS samples in this folder are original project content. Do not
add `common.j`, `Blizzard.j`, or `common.ai` from a Warcraft III installation
to source control or release artifacts.
